# 📈 Experimental Results & Outputs (`results/`)

This directory stores the visual artifacts, segmentation masks, quantitative evaluation tables, and model checkpoints generated by the **Safe Gardens** pipeline.

---

## 📂 Subdirectory Structure

```text
results/
├── figures/        # High-resolution plots, filter comparisons, confusion matrices, ROC curves
├── masks/          # Sample binary lesion masks & segmentation overlays
├── metrics/        # Quantitative evaluation tables (CSV / JSON)
├── models/         # Saved model weights & checkpoints (ignored by Git)
└── README.md       # Documentation (this file)
```

---

## 📊 Tracked Outputs

| Subdirectory | Contents | Tracked in Git? |
| :--- | :--- | :---: |
| [`figures/`](./figures/) | Side-by-side DIP pipeline progressions, CLAHE histograms, confusion matrices, ROC-AUC curves, and runtime comparison charts (`300 DPI` PNG/PDF). | ✅ Yes |
| [`masks/`](./masks/) | Representative K-means ($k=3$), Otsu, and morphologically refined binary lesion masks overlaid on sample PlantVillage leaves. | ✅ Yes |
| [`metrics/`](./metrics/) | Summary CSV/JSON files containing Accuracy, Precision, Recall, F1-Score, ROC-AUC, IoU, Dice, and inference speed (ms/image) for **SVM**, **Random Forest**, and **MobileNetV2**. | ✅ Yes |
| [`models/`](./models/) | Serialized classifier weights (`*.pkl`, `*.joblib`, `*.pth`). Excluded from Git due to file size. | ❌ Ignored |
